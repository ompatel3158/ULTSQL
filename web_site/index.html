Converged Architecture

Four Paradigms. Zero Friction.

No separate database servers. No external vector search daemons. Everything runs through a unified execution planner and storage engine.

AI & Embeddings

AI-Native HNSW Vector Search

First-class VECTOR data type with Hierarchical Navigable Small World (HNSW) graphs. Execute cosine, Euclidean, and inner product similarity queries across 768-dim embeddings in ~6 ms with >99% Recall@10.

SELECT title, VECTOR_DISTANCE(embedding, '[0.12, 0.85, -0.44]') AS dist FROM documents ORDER BY dist ASC LIMIT 5;
Document Store

NoSQL Dotted JSON

Store schema-free JSON payloads and query nested attributes directly using intuitive dotted syntax and PostgreSQL arrow operators.

SELECT name, metadata->>'role' FROM accounts WHERE metadata->>'tier' = 'Pro';
Procedural

PL/SQL Procedural Scripting

Full procedural block execution with DECLARE, BEGIN, LOOP, cursor iterations, and atomic transaction savepoints.

DECLARE v_sum DOUBLE := 0.0; BEGIN FOR i IN 1..10 LOOP v_sum := v_sum + i; END LOOP; END;
Relational Core

Relational SQL & Durable WAL

Standard SQL-92/2016 dialect with cost-based optimization, MVCC lock-free read isolation, slotted page organization, CRC32 checksums, and crash-safe WAL recovery.

INSERT INTO users (id, name, score) VALUES (1, 'Alice', 100) ON CONFLICT (id) DO UPDATE SET score = EXCLUDED.score;

Universal SDKs

One Database. Every Platform.

Connect natively in Flutter, deploy as a backend microservice, or query from Python, Node.js, Go, Rust, or Docker.

# Add to your Dart or Flutter application
dart pub add ultsql

# Usage in code
import 'package:ultsql/ultsql.dart';

final db = Database('./app.db');
await db.init();
final interpreter = Interpreter(db);
final result = await interpreter.executeScript('SELECT * FROM users;');
# Universal Python Client
pip install ultsql

from ultsql import UltSQLClient

db = UltSQLClient("http://localhost:8080")
db.insert("users", {"id": 1, "name": "Alice"})
print(db.query("users"))
# Universal Node.js & TypeScript Client
npm install ultsql

const { UltSQLClient } = require('ultsql');
const db = new UltSQLClient({ host: 'localhost', port: 8080 });
await db.insert('users', { id: 1, name: 'Alice' });
# Official Go Client
go get github.com/ompatel3158/ULTSQL/bindings/go

import "github.com/ompatel3158/ULTSQL/bindings/go"
client := ultsql.NewClient("http://localhost:8080")
