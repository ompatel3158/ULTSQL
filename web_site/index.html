Engine Architecture

Four storage paradigms engineered into one high-performance codebase.

⚡

Switchable Storage Modes

Dynamic switching between 1.2M+ rows/sec In-Memory storage (`:memory:`) and durable disk storage with ACID WAL journaling.

🧠

Native AI Vector RAG

Sub-7ms Cosine and Euclidean similarity search over 768-dimensional float embeddings using HNSW graph indexing.

🌐

TCP Wire Server

Embedded PostgreSQL Wire Protocol server listening on Port 5432 for remote database network connections.

🛠️

Self-Healing Storage

Auto-detects CRC32 page corruption and reconstructs clean storage page states directly from transaction logs.

📲

P2P Offline CRDT Sync

Merges peer database changes over local network without central server infrastructure using Conflict-Free Replicated Data Types.

📁

Direct File SQL Query

Executes live SQL queries directly over external CSV, JSON, and LOG files without table imports or ETL.
