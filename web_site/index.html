4-in-1 Converged Architecture

One embedded database engine replacing multiple fragmented libraries. Eliminate ETL pipelines and sync overhead.

PILLAR 1

Relational SQL Engine

Full DDL & DML, Slotted-Page Tables, B+ Tree Indexes, INNER/LEFT/CROSS JOINs, GroupBy, Window Functions, and ACID transactions.

SELECT u.name, COUNT(o.id) FROM users u INNER JOIN orders o ON u.id = o.user_id GROUP BY u.name;
PILLAR 2

NoSQL Dotted JSON

Query unstructured JSON objects using native dotted-path notation (`profile.address.city`), JSON mutations, and indexable JSON keys.

SELECT name, JSON_EXTRACT(data, 'user.address.city') FROM documents WHERE JSON_EXTRACT(data, 'role') = 'admin';
PILLAR 3

AI Vector RAG Engine

Native HNSW graph indexing for 768-dim and 1536-dim embeddings. Sub-7ms Cosine, Euclidean, and Dot Product SIMD search.

CREATE INDEX idx_v ON docs(vector) USING HNSW; SELECT title, VECTOR_DISTANCE(vector, [0.12, 0.85...]) FROM docs ORDER BY 2 LIMIT 5;
PILLAR 4

PL/SQL Procedural Loop

High-speed PL/SQL scripts with auto-batched transactions. Executes 1,000,000 loop iterations in <800ms with zero UI thread freeze.

DECLARE i INT := 1; BEGIN FOR i IN 1..1000 LOOP INSERT INTO users VALUES (i, 'User ' || i); END LOOP; END;

Frequently Asked Questions (FAQ)

Everything you need to know about what UltSQL is, how to install it, and how it works.

UltSQL is an open-source, converged multimodal database engine written in 100% Pure Dart with zero external C/C++ compiler or runtime dependencies.

It unifies four major database paradigms into a single engine: Relational SQL (ACID transactions, foreign keys, MVCC, window functions, joins), NoSQL JSON (dotted-path querying and indexing), AI Vector RAG Search (native HNSW and IVF-Flat vector indexes for OpenAI, Ollama, and HuggingFace embeddings), and PL/SQL Procedural Scripting (in-engine loops, procedures, and triggers).

UltSQL offers zero-dependency, 1-line automated installers for all major desktop platforms:

  • Windows (PowerShell):
    iwr -useb https://raw.githubusercontent.com/ompatel3158/ULTSQL/main/install.ps1 | iex
  • macOS & Linux (Bash):
    curl -fsSL https://raw.githubusercontent.com/ompatel3158/ULTSQL/main/install.sh | bash

This automatically installs the native ultsql CLI and daemon to your system PATH.

UltSQL provides official packages across package registries:

  • Python: pip install ultsql
    Connect with from ultsql import Client; db = Client('http://localhost:8080').
  • Node.js: npm install ultsql
    Connect with const { UltSql } = require('ultsql'); const db = new UltSql('http://localhost:8080');.
  • Rust: cargo add ultsql
    Add to Cargo.toml: ultsql = "1.0.22".
  • Dart & Flutter: dart pub add ultsql
    Direct embedded database without server processes: final db = Database('./my_data'); await db.init();.

While SQLite and DuckDB are exceptional tabular databases, they require native C/C++ compiler toolchains (CMake, Make, Clang, MSVC) and platform-specific shared libraries (.dll, .dylib, .so). In Flutter and cross-platform apps, native FFI dependencies frequently cause build errors or platform incompatibility.

UltSQL solves this with:

  • Zero C Dependencies: 100% pure Dart compiles effortlessly to all platforms, including in-browser WebAssembly.
  • Built-In Vector Search: Native HNSW vector indexing eliminates the need for separate vector databases like ChromaDB or Pinecone.
  • NoSQL JSON Support: First-class dotted notation queries without complex JSON extraction extensions.
  • PL/SQL Scripting: Procedural loops and logic executed directly in the database engine.
