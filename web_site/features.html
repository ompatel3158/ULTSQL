Converged Engine Capabilities

ULTSQL merges relational tables, schema-less document collections, Redis-style key-value caching, and AI vector embeddings into a unified slotted-page engine written in 100% pure Dart.

Stable

Slotted-Page Storage Engine

Low-level binary slotted pages (4KB/8KB) with zero-copy row deserialization and variable-length record packing directly on disk. 

// Direct vectorized slotted-page batch ingestion
final stmt = db.prepare('INSERT INTO logs VALUES (?, ?, ?);');
stmt.executeBatchSync(batchRows); // Direct binary slot packing
Explore storage modes →
Stable

ARIES WAL & CRC32 Recovery

Sequential append-only Write-Ahead Log with hardware-grade CRC32 integrity checksums on every transaction block. Autonomous crash recovery on boot. 

-- Automated background WAL checkpoints
SET engine_option wal_checkpoint = true;
Read WAL architecture →
Stable

Bottom-Up B+ Tree Construction

Bulk-sorts leaf keys to build indexes in a single cache-coherent sequential pass, achieving sub-millisecond index creation even on massive datasets. 

CREATE INDEX idx_users_age ON users(age);
-- Bottom-up single-pass parent node generation

Prepared Point Lookups

Direct B+ Tree index traversal bypassing AST and parser overhead. Achieves ultra-low latency point reads on prepared statements. 

final stmt = db.prepare('SELECT * FROM users WHERE id = ?;');
final res = stmt.executeSync([DbInt(42)]);

Converged NoSQL Document Store

MongoDB-style collections (`db.collection`), dotted JSON path queries, array operations, and in-place atomic mutations ($set, $inc, $push). 

final users = db.collection('users');
await users.insertOne({'name': 'Alice', 'score': 95000});
final docs = await users.find({'score': {r'$gte': 80000}}).toList();

Redis-Style Key-Value Engine

High-throughput embedded Key-Value cache with hot in-memory lookups, atomic WAL persistence, TTL expiration, and atomic numeric counters. 

await db.kv.set('auth:token', 'xyz', ttl: Duration(hours: 1));
final token = await db.kv.get('auth:token');
await db.kv.incr('hits:counter', 5);

Cross-Model SQL ↔ NoSQL Bridge

Query schema-less collections using standard SQL syntax with dotted path operators (`->>`), or join relational tables with document collections. 

SELECT _id, doc->>'serial' AS dev_serial
FROM collection('devices')
WHERE (doc->'telemetry'->>'battery')::INT > 80;

AI Vector Search & RAG (HNSW)

Integrated Hierarchical Navigable Small World (HNSW) vector graphs. Run sub-millisecond Approximate Nearest Neighbor (ANN) search inside your database. 

CREATE INDEX idx_emb ON docs(embedding) USING HNSW;
SELECT id, vector_distance(embedding, '[0.1, 0.9]') AS d
FROM docs ORDER BY d ASC LIMIT 5;
