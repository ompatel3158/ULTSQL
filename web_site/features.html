Engine Features & Innovations

Discover how UltSQL combines cutting-edge database research into a unified, zero-dependency pure Dart database engine.

FEATURE 03

HNSW Vector RAG Graph

Sub-7ms Cosine & Euclidean similarity search over 768-dim embeddings with high-recall approximate nearest neighbor accuracy.

FEATURE 04

PostgreSQL Wire Protocol (Port 5432)

Embedded TCP server engine allowing standard PostgreSQL drivers and tools to query UltSQL directly.

db.startPgWireServer(port: 5432);
FEATURE 05

PL/SQL Engine & Loops

Auto-batched procedural loops with local environment scopes executing 1M loop iterations in <800ms.

FOR i IN 1..1000 LOOP ... END LOOP;
FEATURE 06

NoSQL Dotted Path Queries

Query unstructured JSON objects using native dotted-path notation (`profile.address.city`).

SELECT data.user.name FROM docs;
FEATURE 07

Self-Healing WAL Recovery

Automatic write-ahead log crash recovery with IEEE 802.3 CRC32 page checksumming.

db.recoverFromWalSync();
FEATURE 08

Offline P2P Mesh Sync

Local-first P2P mesh synchronization powered by LWW-Element-Set CRDTs.

db.syncPeer(peerState);
FEATURE 09

Universal Direct File Queries

Query external CSV, JSON, and LOG files directly without ETL or table import.

SELECT * FROM READ_CSV('logs.csv');
FEATURE 10

Multi-Process File Locking

Cross-process exclusive file locking prevents WAL corruption when multiple processes access the same database file concurrently.

throw DatabaseLockException('Database locked');
