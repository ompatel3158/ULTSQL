Engine Architecture Matrix

Converged Multimodal Architecture

ULTSQL is engineered with zero compromises: real ACID relational storage, high-dimensional vector graphs, JSON document indexes, and PL/SQL procedural loops.

PURE DART RUNTIME

100% Pure Dart VM & Wasm

Requires zero CMake, NDK, Xcode toolchain bindings, or dynamic `.so` / `.dylib` loading. Compiles cleanly across Flutter iOS, Android, macOS, Windows, Linux, and Web.

STORAGE KERNEL

Slotted Page Architecture with CRC32

Built with 4KB fixed slotted disk pages with variable-length record slots. Every single page header verifies data integrity using hardware CRC32 checksums on disk read.

CONCURRENCY

MVCC Snapshot Isolation

Multi-Version Concurrency Control maintains transaction snapshots. Readers do not block writers, and writers do not block readers, preventing database lock contention.

CRASH RECOVERY

ARIES Write-Ahead Logging (WAL)

All mutations are written sequentially to an append-only WAL log before flushing to slotted tables, ensuring zero data loss upon abrupt process termination.

AI VECTOR RAG

Native HNSW Vector Indexing

Integrated Hierarchical Navigable Small World vector index supporting Cosine, Euclidean, and Dot Product distance metrics with SIMD-optimized math.

WIRE PROTOCOL

PostgreSQL Wire Protocol Server

Embed a Pgwire TCP server directly into your Dart app. Connect standard PostgreSQL tools (psql, DBeaver, TablePlus, Grafana) directly to your local database.
