Why UltSQL Sustains Sub-Millisecond Speed

  • Zero-Allocation `RowMap` Tuple View: Replaces dynamic map allocations with zero-allocation schema index views.
  • JIT Compiled Expressions: Compiles SQL `WHERE` conditions into native Dart closure delegates.
  • Slotted Page Buffer Pinning: Keeps hot pages pinned in PageCache to eliminate disk file unpinning overhead.
  • Sequential B+ Tree Batch Ingestion: `insertSortedBatchSync` writes sorted key ranges directly into leaf nodes in $O(N)$ linear passes.
