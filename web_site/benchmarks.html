dart run tool/benchmarks/benchmark_beat_sqlite.dart
HARDWARE ENVIRONMENT

Testing Rig Specifications

• CPU: Apple M3 Max (14 Cores) / AMD Ryzen 9 7950X
• RAM: 36 GB Unified / 64 GB DDR5
• OS: macOS 15.0 & Windows 11 Pro
• Dart SDK: 3.6.0 Stable / Wasm AOT

KEY FINDINGS

Why ULTSQL Leads

Zero C/Dart FFI marshalling overhead. Slotted page structures are laid out directly in contiguous typed byte buffers (`Uint8List`), removing pointer conversion penalties and GC pressure.
