Empirical Performance

Verified Benchmarks

Performance measurements evaluated across disk persistence, batch ingestion, B+ Tree indexing, and HNSW vector similarity search.

Benchmark Test Environment & Disclosure

ASUS ROG Strix G16 (2023)

Performance throughput was empirically benchmarked by Om Patel on local NVMe disk with WAL durability enabled, using a synthetic 100,000-row test dataset (id INT, name VARCHAR, score DOUBLE, active BOOL, payload JSON, ~18.5 MB database footprint).

CPU
Intel Core i7-13650HX
RAM
16 GB DDR5 (4800 MT/s)
Disk I/O
1 TB Gen 5 NVMe SSD
Platform
Dart 3.12 (AOT / JIT)

Run the Reproducible Benchmark Suite

Every developer can clone the repository and verify these measurements locally on their own machines:

git clone https://github.com/ompatel3158/ULTSQL.git cd ULTSQL dart run tool/benchmarks/benchmark_live_comparison.dart
