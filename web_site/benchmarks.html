Reproduce These Benchmarks On Your Machine

Clone the repository and run the open-source benchmark harness directly via Dart:

Terminal (PowerShell / Bash) 
# 1. Clone ULTSQL
git clone https://github.com/ompatel3158/ULTSQL.git
cd ULTSQL

# 2. Run automated comparative benchmark harness (relational, nosql, kv, vector)
dart run tool/benchmarks/run_all.dart --rows 50000 --runs 3 --big 200000

# Results will be generated and saved to web_site/data/benchmarks.json
