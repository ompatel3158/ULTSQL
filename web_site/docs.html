Introduction to ULTSQL

ULTSQL is an embedded, multimodal database engine written in 100% pure Dart. It uniquely combines a relational SQL execution engine with ACID MVCC guarantees, native HNSW high-dimensional vector search, schema-less JSON document storage, and a procedural PL/SQL runtime into a single lightweight package.

Zero C/C++ Dependencies: Runs entirely in pure Dart bytecode and Dart WebAssembly. Works identically across iOS, Android, macOS, Windows, Linux, and Web.

Installation

Add ULTSQL to your Dart or Flutter application:

TERMINAL 
dart pub add ultsql

For Flutter applications:

TERMINAL 
flutter pub add ultsql

Quickstart Guide

Create an in-memory database or open an existing single-file `.ultsql` database with automatic WAL recovery:

DART (main.dart) 
import 'package:ultsql/ultsql.dart';

void main() async {
  // 1. Open persistent single-file database
  final db = await UltSqlDatabase.openFile('app.ultsql');

  // 2. Create multimodal table
  await db.execute('''
    CREATE TABLE users (
      id INT PRIMARY KEY,
      name VARCHAR(100),
      embedding VECTOR
    );
  ''');

  // 3. Insert record
  await db.execute('''
    INSERT INTO users VALUES (1, 'Om Patel', '[0.12, 0.88, -0.45]');
  ''');

  // 4. Query record
  final rows = await db.query('SELECT * FROM users WHERE id = 1;');
  print(rows);
}

AI Vector Search & RAG (HNSW)

Native Hierarchical Navigable Small World (HNSW) graph index in pure Dart. Store high-dimensional embeddings and compute vector similarity with sub-millisecond latencies.

SQL VECTOR QUERY 
SELECT title, VECTOR_DISTANCE(embedding, '[0.15, 0.72, -0.30]') AS distance
FROM knowledge_base
ORDER BY distance ASC
LIMIT 3;

Embedded Pgwire Server

Start a PostgreSQL wire protocol server inside your Dart process. Standard PostgreSQL clients (psql, DBeaver, TablePlus, Grafana) can connect over TCP socket on port 5432.

DART (pgwire_server.dart) 
import 'package:ultsql/ultsql.dart';

void main() async {
  final db = await UltSqlDatabase.openFile('shared.ultsql');
  final server = PgwireServer(db, port: 5432);
  await server.start();
  print('Pgwire listening on 127.0.0.1:5432');
}
