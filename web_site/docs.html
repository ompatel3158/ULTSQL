UltSQL Documentation

The complete manual for starting the engine, connecting clients, running CLI commands, and utilizing advanced multimodal SQL features.

1. Starting the UltSQL Server Daemon

Choose the server startup method for your operating system or language stack.

METHOD A

🖥️ 1-Line CLI Auto-Installer (Windows, Linux, macOS)

No Flutter, Dart, Python, or Node required. Automatically downloads binary and configures your system PATH:

# Windows (PowerShell)
iwr -useb https://raw.githubusercontent.com/ompatel3158/ULTSQL/main/install.ps1 | iex

# Linux & macOS (Bash)
curl -fsSL https://raw.githubusercontent.com/ompatel3158/ULTSQL/main/install.sh | bash
METHOD B

🐍 Python `ultsql-server` CLI

When installed via pip install ultsql, launch the server directly from Python terminal:

pip install ultsql

# Start daemon
ultsql-server --port 8080 --db ./my_database
METHOD C

🐳 Docker Container

Run UltSQL in production cloud servers or Kubernetes with zero local installation:

docker run -p 8080:8080 -v ./data:/db ompatel3158/ultsql serve --port 8080 --db /db

2. CLI Terminal Commands & Interactive Meta-Commands

All interactive terminal commands available inside the ultsql CLI prompt.

Command Description Example
ultsql serve [--port 8080] [--db path] Launches the HTTP REST daemon and live OpenAPI 3.0 specification server. ultsql serve --port 8080 --db ./app.db
.pgwire [port] Starts the PostgreSQL Wire Protocol server daemon inside CLI session. .pgwire 5432
.tables Lists all tables in the active catalog schema. .tables
.schema [table] Shows DDL schema definition and column types for a table. .schema users
.databases Displays active database storage path. .databases
.exit / exit Flushes WAL logs and safely exits the interactive prompt. .exit

3. Python Package (`pip install ultsql`)

Official PyPA compliant client library. Zero Dart/Flutter setup required!

# 1. Install via pip
pip install ultsql

# 2. Connect and execute in Python
from ultsql import UltSQLClient

# Connect to UltSQL Daemon
db = UltSQLClient("http://localhost:8080")

# Insert record (auto-provisions table schema if missing)
db.insert("products", {"id": 1, "name": "Quantum Laptop", "price": 1299.99})

# Fetch records
result = db.query("products")
print("Count:", result["count"])
print("Rows:", result["rows"])

# Fetch OpenAPI Specification
spec = db.openapi_spec()
print("OpenAPI Title:", spec["info"]["title"])

4. Node.js & TypeScript Package (`npm install ultsql`)

Official Node.js & TypeScript client library with full type definitions.

// 1. Install via npm
npm install ultsql

// 2. Connect and execute in JavaScript / TypeScript
const { UltSQLClient } = require('ultsql');

const db = new UltSQLClient({ host: 'localhost', port: 8080 });

async function run() {
  // Insert record
  await db.insert('users', { id: 101, name: 'Om Patel', tier: 'VIP' });

  // Query records
  const result = await db.query('users');
  console.log('Users:', result.rows);
}

run();

5. Advanced Multimodal SQL Features Syntax

Syntax guide for UltSQL's advanced multimodal engine capabilities.

⚡ Reactive Query Streams (`db.watch()`)

final stream = db.watch(interpreter, "SELECT * FROM users WHERE active = true");
stream.listen((result) {
  print("Updated rows: ${result.rows}");
});

🔄 SQL Macros (`CREATE MACRO`)

CREATE MACRO calculate_tax(amount) AS amount * 0.15;
SELECT id, price, calculate_tax(price) AS tax FROM orders;

📡 Event Streams (`CREATE STREAM`)

CREATE STREAM order_events;
EMIT TO order_events VALUES (101, 'order_placed', NOW());

🌿 Database Branching (`ultsql branch`)

db.createBranch('feature-dev');
db.switchBranch('feature-dev');
db.mergeBranch('feature-dev', 'main');
