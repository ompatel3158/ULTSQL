What is the ULTSQL license? ▾
ULTSQL uses a source-available license. It allows developers and companies to use, modify, distribute, and commercially use ULTSQL without paying royalties for permitted uses. However, offering ULTSQL itself as a commercial hosted database service requires a separate commercial license.
Can I use ULTSQL for free in my commercial application? ▾
Yes. You can build and sell a commercial application that uses ULTSQL without paying any license fee, provided you include the required attribution (“Powered by ULTSQL”) and do not offer ULTSQL itself as a commercial hosted database service.
Do I have to open-source my own application? ▾
No. This license does not require your application to become open source. You can keep your own application's source code 100% proprietary.
Where should the “Powered by ULTSQL” attribution appear? ▾
It should appear in an appropriate location such as an About, Legal, Licenses, Credits, or Documentation section of your product, along with a link to the official ULTSQL repository or website. It does not need to be on the primary application interface.
Can I use ULTSQL in a SaaS application? ▾
Yes. For example, you can build an accounting SaaS, an analytics SaaS, or an AI application powered by ULTSQL. That is fully permitted because ULTSQL is being used as part of a larger product.
Can I run ULTSQL on AWS, GCP, or Azure for my company? ▾
Yes. Internal cloud deployment is permitted. You can run ULTSQL on any cloud provider for your own application, organization, testing, or internal infrastructure. The restriction applies only to offering ULTSQL itself as a hosted database service to external customers.
Can I modify ULTSQL and distribute my changes? ▾
Yes. You can modify the source code and create derivative versions. Your modifications remain subject to the applicable requirements of the ULTSQL license when distributed.
Is ULTSQL free for students, researchers, and startups? ▾
Yes. Educational, research, and startup use is royalty-free under the license terms.
What is the simplest summary of the license? ▾
  • Use ULTSQL → Free

  • Sell that application → Allowed
  • Run ULTSQL internally on the cloud → Allowed

  • Remove required attribution → Not allowed
